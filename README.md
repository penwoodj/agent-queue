# agent-queue

Complex multi-dimensional queue workflow engine for [`yaml-to-rust-agentsdk`](https://github.com/penwoodj/yaml-to-rust-agentsdk).

## Overview

`agent-queue` is a project scaffold for coordinating queue-driven agent workflows with YAML-defined execution paths and a Rust-oriented SDK target.

The current repository is intentionally lightweight while the workflow model, queue semantics, and runtime boundaries are still being shaped.

## Focus Areas

- 🧭 Multi-dimensional queue orchestration
- 🧩 YAML-defined workflow composition
- 🦀 Rust Agent SDK integration direction
- 🔀 Branch-based iteration for early engine design
